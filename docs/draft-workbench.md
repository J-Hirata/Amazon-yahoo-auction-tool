# ヤフオク出品下書きの作業場

## 現在地と目的

2026-11-10。従来の「下書き候補10件」「待機（枠外の準備済み＋情報不足）」「直近20件の履歴」の混在を解消し、一つの商品カード一覧を作業状態で切り替える。登録データ・手入力・既存の保存記録を削除・移行・初期化しない。

## 状態と操作

| 表示 | 保存状態 | 次の操作 |
|---|---|---|
| これから出す | 準備済み・情報待ち・下書き保存済み | 出したい順に並べ替える |
| 出品準備できた | ready_for_draft | 文面・写真・価格・現物を確認し、ヤフオクへ進む |
| 情報を補う | waiting_for_product_data 等 | 不足欄を編集し「保存して準備完了」。商品名と参考価格が必要 |
| 保存済み・出品未記録 | draft_saved | Yahoo側の現在の出品状況を確認し、出品済みなら手動記録 |
| 出品済み | listed | ヤフオクの実際の販売状態を別途確認 |
| 保留・売却済み | archived / sold / deleted | 必要に応じて編集から準備へ戻す |

- 一覧は1商品1枚。履歴の重複表示と直近20件制限を廃止。準備済みは10件を超えても全部表示。CSVは既存仕様の作業順先頭10件と明記する。
- 写真付きタイルを初期表示とし、小・標準・大とリストを選べる。表示設定はブラウザー、作業順は各商品の workPriority にクラウド保存する。ドラッグ、矢印、キーボード移動に対応。絞り込み中は見えている商品の位置だけ入れ替え、隠れた商品の順を保つ。「次の下書き文面」とCSVも準備済み商品の保存順を使う。
- 長い説明・写真URL・参考価格・状態は編集ダイアログへ分離。入力ごとの自動保存をやめ、変更した欄だけを明示保存する。日付・手入力価格・他欄をコピーして上書きしない。競合時は一覧だけ最新化して編集フォームを保持する。
- 下書き保存済み・出品済みは本人の手動記録。実際のYahooへの保存・出品を自動実行した証拠ではない。クラウドとPC版の自動同期・クラウドからの拡張入力は未接続のまま。使い方の折りたたみに対応範囲を明記する。

## 写真・商品名

- 既存の登録写真を優先する。欠けている写真は、同じASINの取得済みAmazonカタログ写真を表示用に参照する。別ASINや自社在庫の現物写真を推定流用しない。この参照表示と文面生成はDBへ保存しない。
- 「写真・商品名を補完」は現在の一覧/検索に表示する商品を対象に、1回5件以下へ分割して取得する。各カードから1商品の取得も可能。新規ASIN登録後はその入力分だけ補完する。
- 新規取得は既存の日本向けAmazon Catalog Items APIの読み取りを利用する。タイトル・MAIN画像のASIN一致を検証。説明・参考価格・作業状態・保存済み日時は触らない。既存の写真URLがあれば書き換えない。未取得はAmazonリンクと編集へ誘導する。
- 操作は本人認証、同一Origin、JSON、If-Match、閲覧専用ガードを維持。5件の不足分を1トランザクションで保存し、並行編集があれば全件拒否。外部出品・数量・メール・Cronには接続しない。
