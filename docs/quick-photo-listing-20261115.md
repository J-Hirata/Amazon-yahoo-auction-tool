# 写真からヤフオク・メルカリ下書きへ（2026-11-15）

## 現在地
写真仕分けナビの「調べて出品準備」から、同じ商品IDと現写真セットを保って販売コックピットへ進む。公開URLの反映状況は両プロジェクトのoutput/quick-listing-20261115/release.jsonを参照する。実際の出品・公開は行わない。

## 操作
1. 写真ナビの商品カードで販売先を選び「調べて出品準備」へ進む。グループ作成は不要。検索ワードだけで始められる。
2. 型番が足りなければ自分の保存写真・切り抜き・貼付画像を読み取り、候補を修正して検索する。
3. 落札/売却済み候補を確認し、比較する記録と参考URLを選ぶ。価格幅・中央値は選んだ未照合候補の参考で、確定相場ではない。サイトの状態をA/B/Cへ推測変換しない。
4. 自分の写真に基づく状態・付属品・動作確認・価格を確認し「写真下書きへ進む」を押す。
5. 販売コックピットの下書きツール内で写真・文面・価格を確認して保存する。ZIPで写真と文面を取得し、各サイトの入力画面へ進める。これはツール内保存でありサイトでの出品完了ではない。

## 既存機能を保つ受け渡し
photo-package/v1とresearch-context/v1を互換拡張する。queryとphotoIdsは任意。選択写真が現商品・同じsourceDigestに属するか検査する。Amazon/Keepa取得がない商品も写真下書きへ進める。Yahooの旧下書きIDを維持し、メルカリは同一商品でも別ID。既存下書きの本人編集・在庫紐付け・数量・通知・Cronを上書きしない。

## 公開ページの読取り
/api/research/pageは既存の署名・読取り許可を照合する。固定のYahoo/Mercari公開URLだけを取得し、リダイレクト・認証転送はしない。最大2MB・15秒・最大50候補・操作IDの再送照合。制限/取得不可は検索画面のリンクへ戻る。
Yahooは実ページの対象一覧/対象商品データだけを採用し、終了時刻と入札の根拠がある価格を落札額として扱う。広告・おすすめを採らない。税抜/税込・送料不明を混同しない。Mercariは当該商品のschemaで確認できる情報のみ。SoldOutは売却済み表示価格、OutOfStockだけでは売却確定しない。検索一覧の自動収集は確認できておらず、手動検索と参考URLを併用する。
参考URLは出典として保持し、他人の写真・独自説明・動作保証・その品だけの傷を流用しない。
